# CUET_BUS

CUET_BUS is a web-based bus ticket booking system developed for the Chittagong University of Engineering & Technology (CUET). This application allows users to view available buses, purchase tickets, and manage their bookings efficiently.

## Features

- **User Registration & Authentication**: Secure sign-up and login functionalities for users.
- **Bus Listings**: Browse through available buses with details like departure time, destination, and seat availability.
- **Ticket Booking**: Seamless ticket purchasing process with real-time seat updates.
- **Booking History**: Users can view their past bookings and transaction details.
- **Admin Panel**: Administrative interface to manage buses, routes, and user information.

## Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP
- **Database**: MySQL
- **Additional Tools**: jQuery, Bootstrap
